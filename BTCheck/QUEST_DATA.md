# BTCheck 2.0.0 任务数据审计

## 范围与原则

- 目标版本：TBC 周年服 2.5.6 / Interface 20506。
- 正式追踪5条团本开门任务线；另外4个团本只显示“无需个人开门”。
- 同一逻辑步骤中的多个Quest ID为二选一，完成任意一个只计1步。
- 并行但都必须完成的任务分别列为不同逻辑步骤。
- 插件只判断任务是否在日志中、是否已完成，不读取任务目标物品数量。

资料来源：当前周年服[团本开门总览](https://www.wowhead.com/tbc/guide/attunement-dungeons-raids-burning-crusade-classic)、[Phase 3 开门要求调整](https://www.wowhead.com/tbc/news/previous-phase-attunement-requirements-will-be-removed-the-burning-crusade-382590)、简体中文TBC任务数据页，以及现有20506接口审计。任务数据页只用于Quest ID、任务名称与任务链关系，不作为Lua API依据。
