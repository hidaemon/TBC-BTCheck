# BTCheck — 黑暗神殿开门进度

BTCheck 是面向《魔兽世界》TBC 周年服 2.5.6（Interface 20506）的简体中文任务清单插件。它记录每个登录过角色的黑暗神殿开门任务进度，并在同一本机、同一 WoW 账号的角色之间共享快照。

## 安装

1. 将整个 `BTCheck` 文件夹复制到：
   `World of Warcraft/_anniversary_/Interface/AddOns/`
2. 确认最终路径为：
   `.../_anniversary_/Interface/AddOns/BTCheck/BTCheck.toc`
3. 进入游戏，在角色选择界面启用 **BTCheck - 黑暗神殿开门进度**。
4. 输入 `/btcheck` 打开列表。

插件只接受客户端版本 `2.5.6` 且 Interface 为 `20506`。如果玩家强制在其他版本加载，插件会停止扫描并在聊天框报告原因。

## 使用

- `/btcheck`：打开或关闭进度表。
- `/btcheck refresh`：立即刷新当前角色。
- `/btcheck chars`：打开角色管理。
- `/btcheck reset`：重置主窗口与小地图按钮位置。
- `/btcheck help`：显示命令帮助。

主表以任务为行、角色为列。任务行最右侧显示未隐藏角色中“已完成＋进行中”的总人数；悬停任务行可查看已完成和进行中的人数明细。绿色表示已完成，黄色表示正在进行，灰色表示未开始。前四步的奥尔多与占星者任务 ID 是互斥分支，每一步只计算一次，所以总进度固定为 16 步。

未开始第一个逻辑步骤的非当前角色会自动隐藏，并在“角色管理”中标注“自动隐藏｜未开始开门任务”；当前登录角色即使尚未开始第一步仍会保留在主表中。手动点击“恢复”后，该角色不会再次被自动隐藏，直到其第一步状态发生变化。

角色管理每页显示 10 个角色，底部保留分页按钮。

角色名称按 TBC 职业颜色显示；缺少职业信息的历史快照使用白色，不影响进度状态颜色。

主表底部横向滚动条用于左右切换角色列；直接拖动滑块或在滚动条上滚轮均可移动角色列。

主表右上方的“搜索角色”输入框支持按角色名模糊搜索（包含匹配，不区分英文字母大小写）；输入内容会即时筛选角色列和每行人数，按 Esc 或点击“清除”可恢复全部角色。

## 数据范围

- 使用账号级 `BTCheckDB` SavedVariables，可汇总同一本机、同一 WoW 账号下登录过的跨服务器和跨阵营角色。
- 当前角色会回查安装插件前已经完成的任务。
- 离线角色显示最后一次扫描的快照和时间。
- 不支持跨电脑、不同 WoW 子账号或战网云端同步。
- 账号开门状态仅根据插件已经记录的角色推断。
- 跟踪终点是 Quest `10985`「帮助阿卡玛」，不包含伊利丹后续任务。

## 兼容性原则

插件不包含 Ace、LibStub 或其他第三方运行库；不使用 Retail ScrollBox、Menu、Settings、`C_AddOns` 或旧版任务日志兼容函数。完整接口依据和验证结果见 `API_AUDIT.md`。
