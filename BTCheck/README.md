# BTCheck 2.0.0 — TBC 团本开门进度

BTCheck 是面向《魔兽世界》TBC 周年服 2.5.6（Interface 20506）的简体中文团本开门任务插件。它记录每个登录角色的任务进度，并通过账号级 `BTCheckDB` 汇总同一本机、同一 WoW 账号下的跨服务器、跨阵营角色快照。

## 团本范围

插件总览包含全部 9 个 TBC 70级团本：

| 团本 | 人数 | 插件状态 |
| --- | ---: | --- |
| 卡拉赞 | 10 | 8个逻辑步骤；任务线保留，当前阶段已取消强制进入要求 |
| 格鲁尔的巢穴 | 25 | 无个人开门任务；标注其与毒蛇神殿任务的关系 |
| 玛瑟里顿的巢穴 | 25 | 无个人开门任务；标注其与风暴要塞试炼的关系 |
| 毒蛇神殿 | 25 | `10901`「卡达什圣杖」；Phase 3 已取消强制进入要求 |
| 风暴要塞 | 25 | 30个逻辑步骤，包含诅咒密码和4项纳鲁试炼；Phase 3 已取消强制进入要求 |
| 海加尔山之战 | 25 | `10445`「永恒水瓶」 |
| 黑暗神殿 | 25 | 原有16个逻辑步骤、20个Quest ID完整保留 |
| 祖阿曼 | 10 | 无个人开门任务 |
| 太阳之井高地 | 25 | 无个人开门任务；服务器阶段进度单独说明 |

完整Quest ID和逻辑步骤见 `QUEST_DATA.md`。

## 界面与行为

- “总览”页面一次展示9个团本、当前角色进度、账号完成记录和当前进入要求。
- 点击团本按钮进入任务详情页；任务为行、角色为列。
- 当前登录角色固定第一列，不参与排序，也不会因没有任务进度而隐藏。
- 从第二列开始，按当前所选团本已完成步骤数从高到低排序。
- 每页显示5个角色列、16个任务行；风暴要塞超过16步，可使用右侧滚动条。
- 黑暗神殿恰好16步，仍可完整显示在一个屏幕内。
- 主表角色名使用TBC职业颜色，支持角色名模糊搜索。
- 每行人数只统计未隐藏角色中已完成或进行中的人数。
- 所有5条任务线均无任何进度的非当前角色会自动隐藏；可以在角色管理中恢复。
- 角色管理支持隐藏、恢复和确认删除全部团本快照。
- 小地图按钮左键切换窗口，可拖动并保存位置。

任务线完成度与当前进入资格是两个独立状态。周年服部分旧团本已经取消强制开门，但插件仍保留这些任务线的角色进度。

## 数据升级

2.0.0 将数据库结构升级为版本2：

```text
character.raids[raidKey].quests[questID] = status
```

从1.x升级时，旧的 `character.quests` 会无损迁移至 `character.raids.black_temple.quests`，角色GUID、职业、阵营、服务器、同步时间、隐藏设置、窗口位置和小地图位置均会保留。数据库版本高于插件支持版本时会停止运行，避免覆盖未来数据。

## 安装与命令

将整个 `BTCheck` 文件夹复制到：

```text
World of Warcraft/_anniversary_/Interface/AddOns/
```

确认最终路径为 `.../Interface/AddOns/BTCheck/BTCheck.toc`，然后在角色选择界面启用插件。

| 命令 | 作用 |
| --- | --- |
| `/btcheck` | 打开或关闭主窗口 |
| `/btcheck refresh` | 刷新当前角色的全部任务线 |
| `/btcheck chars` | 打开角色管理 |
| `/btcheck reset` | 重置窗口和小地图按钮位置 |
| `/btcheck help` | 显示命令帮助 |

## 兼容性边界

- 目标客户端固定为 `2.5.6 / 20506`；其他版本停止扫描并提示错误。
- 只使用经过20506资料审计的 `C_QuestLog.IsQuestFlaggedCompleted`、`C_QuestLog.IsOnQuest`、角色身份、时间与基础Frame接口。
- 不读取未经核实的任务目标数量，因此“卡达什圣杖”和“永恒水瓶”只显示未开始、进行中或已完成。
- 不使用Ace、LibStub、Retail ScrollBox/Menu/Settings、`C_AddOns` 或过时任务日志兼容函数。
- 账号完成状态只根据本机已记录角色推断；不跨电脑、不同WoW子账号或战网云端同步。

接口依据见 `API_AUDIT.md`，客户端测试步骤见 `TESTING.md`。
