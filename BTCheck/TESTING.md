# BTCheck 2.0.0 测试清单

## 自动测试

```sh
luac -p BTCheck/Data.lua BTCheck/Core.lua BTCheck/UI.lua
lua BTCheck/tests/mock_spec.lua BTCheck
lua BTCheck/tests/ui_smoke.lua BTCheck
```

自动测试覆盖：

- 9个团本注册表、5条正式任务线及固定分母。
- 1.x `character.quests` 到2.0黑暗神殿快照的无损迁移。
- 卡拉赞、毒蛇神殿、风暴要塞、海加尔和黑暗神殿独立进度。
- 奥尔多/占星者与联盟/部落二选一不重复计数。
- 团本之间的账号完成状态不串线。
- 当前角色固定第一列、其他角色按所选团本完成步骤排序。
- 总览9张卡片、10个选择按钮、无开门说明页和风暴要塞纵向滚动。
- 搜索、职业染色、角色管理、关闭按钮和小地图按钮。
- 非20506客户端失败关闭。

## 客户端预检

在TBC周年服2.5.6客户端中执行：

```text
/console scriptErrors 1
/reload
/run local v,b,d,t=GetBuildInfo(); print(v,b,d,t)
/run print(type(C_QuestLog.IsQuestFlaggedCompleted), type(C_QuestLog.IsOnQuest))
```

预期版本为 `2.5.6`，Interface为 `20506`，两个任务函数均输出 `function`。

## 数据迁移验收

1. 使用已有1.1.x SavedVariables登录。
2. 确认原有黑暗神殿进度、角色列表、隐藏状态和位置未丢失。
3. 退出游戏后检查 `BTCheckDB.version == 2`。
4. 确认旧进度位于 `characters[GUID].raids.black_temple.quests`。
5. 不要手动编辑真实SavedVariables；测试前保留备份。

## 团本功能矩阵

- 总览：显示全部9个团本，5条任务线与4个无需个人开门团本数量正确。
- 卡拉赞：分母固定8，历史完成任务可回查。
- 毒蛇神殿：`10901`接受后黄色、交付后绿色；不显示未经核实的Boss目标数量。
- 风暴要塞：分母固定30；三条碎片支线与三项前置试炼可并行；右侧滚动条范围为14行。
- 海加尔：`10445`接受后黄色、交付后绿色。
- 黑暗神殿：分母固定16，16行在一屏完整显示；前四步分支不重复计数。
- 格鲁尔、玛瑟里顿、祖阿曼、太阳之井：只显示“无需个人开门”说明，不出现任务行或0/0伪进度。
- 当前进入要求：SSC/TK显示Phase 3已取消强制门槛；任务进度仍可查看。

## 跨角色与UI

- 当前登录角色固定第一列，即使没有开始任何任务也保持显示。
- 第二列开始按当前所选团本完成步骤数降序；切换团本后重新排序。
- 完全没有5条任务线进度的离线角色自动隐藏，并在角色管理标注。
- 角色管理的恢复、隐藏、删除作用于角色的全部团本快照。
- 账号完成角色名单按所选团本独立汇总。
- 至少准备6个角色验证横向滚动、搜索过滤和行人数统计。
- 验证主窗口、关闭按钮、小地图按钮、拖动位置和 `/reload` 后持久化。
- 战斗内外、野外、副本、团队副本、切换地图、退出重登均无Lua错误或保护操作污染。
