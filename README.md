# BTCheck · 黑暗神殿开门进度

BTCheck 是面向《魔兽世界》TBC 周年服的简体中文任务进度插件，用于跟踪黑暗神殿（Black Temple）开门任务线，并在同一本机、同一 WoW 账号下汇总已登录角色的进度。

当前版本：`1.1.5`  
目标客户端：`TBC 2.5.6` / `Interface 20506`  
作者：达蒙

## 功能概览

- 跟踪黑暗神殿开门任务线的 16 个逻辑步骤、20 个任务 ID。
- 奥尔多与占星者前四步按阵营二选一计算，不会重复计数。
- 任务为行、角色为列的进度表，首屏最多显示 5 个角色。
- 绿色表示已完成，黄色表示进行中，灰色表示未开始。
- 角色名按 TBC 职业颜色显示，缺少职业信息的历史快照使用白色。
- 主表支持角色名模糊搜索，输入后即时筛选角色列和每行人数统计。
- 支持横向切换角色列、任务行滚轮查看，以及固定任务标题区域。
- 角色管理支持隐藏、恢复和确认删除旧角色快照。
- 未开始第一步的非当前角色会自动隐藏；当前登录角色仍会保留显示。
- 顶部汇总账号开门状态，并显示已完成终点任务的角色。
- 小地图按钮可点击打开窗口、拖动调整位置并保存位置。

## 跟踪范围

插件跟踪黑暗神殿开门任务线，终点为 Quest `10985`「帮助阿卡玛」。前四步的阵营分支如下：

| 逻辑步骤 | 奥尔多 | 占星者 |
| --- | ---: | ---: |
| 巴尔里石板 | `10568` | `10683` |
| 长者奥洛努 | `10571` | `10684` |
| 灰舌腐蚀者 | `10574` | `10685` |
| 守望者的牢笼 | `10575` | `10686` |

后续共用任务为 `10622`、`10628`、`10705`、`10706`、`10707`、`10708`、`10944`、`10946`、`10947`、`10948`、`10949`、`10985`。插件不跟踪任务目标数量，也不包含伊利丹后续的 `10957`、`10958`、`10959` 等任务。

## 安装

1. 下载或复制仓库中的 `BTCheck` 文件夹。
2. 将整个文件夹放入：

   ```text
   World of Warcraft/_anniversary_/Interface/AddOns/
   ```

3. 确认最终文件路径为：

   ```text
   .../_anniversary_/Interface/AddOns/BTCheck/BTCheck.toc
   ```

4. 在角色选择界面启用“BTCheck - 黑暗神殿开门进度”。
5. 进入游戏后输入 `/btcheck` 打开窗口。

插件启动时会校验客户端版本和 Interface 号。不是 `2.5.6 / 20506` 时会停止扫描并在聊天框提示版本不匹配。

## 使用方式

### 斜杠命令

| 命令 | 作用 |
| --- | --- |
| `/btcheck` | 打开或关闭主窗口 |
| `/btcheck refresh` | 刷新当前角色任务状态 |
| `/btcheck chars` | 打开角色管理 |
| `/btcheck reset` | 重置主窗口和小地图按钮位置 |
| `/btcheck help` | 显示命令帮助 |

### 角色搜索

主窗口右上方的“搜索角色”输入框支持包含匹配。例如输入角色名中的任意连续片段，即可筛选出对应角色；英文字母搜索不区分大小写。搜索会同步影响主表角色列、横向滚动范围和任务行人数统计。按 `Esc` 或点击“清除”可恢复全部可见角色。

搜索遵循主表的可见性规则：被隐藏的角色不会出现在主表搜索结果中，但仍可在“角色管理”中查看和恢复。

### 状态和角色管理

- 悬停任务行可查看该任务已完成和进行中的人数。
- 悬停角色标题可查看职业、阵营、进度和实时/离线快照信息。
- 离线角色显示最后一次同步快照和时间。
- 删除角色会移除本机快照；该角色下次登录并加载插件后会重新建立记录。

## 数据与隐私

- 使用账号级 SavedVariables：`BTCheckDB`。
- 只汇总同一台电脑、同一 WoW 账号下登录过的角色，不提供跨电脑、不同 WoW 子账号或战网云端同步。
- 插件会在本机保存角色 GUID、角色名、服务器、职业、阵营、任务状态和最后同步时间，以便识别角色和显示离线快照。
- 仓库只包含插件源代码、文档和测试，不包含任何玩家的 `BTCheckDB` 数据。
- 分享游戏目录或 SavedVariables 文件前，请先检查其中是否包含自己的角色信息。

## 兼容性与安全边界

插件无第三方运行库，不依赖 Ace3、LibStub 或其他外部库；不使用 Retail 专用的 ScrollBox、Menu、Settings、`C_AddOns`，也不回退到旧版任务日志兼容函数。

实现只使用目标客户端 2.5.6/20506 已核对的任务、角色、时间和基础界面接口，并在加载时检查必需接口。详细接口来源见 [`BTCheck/API_AUDIT.md`](BTCheck/API_AUDIT.md)。
